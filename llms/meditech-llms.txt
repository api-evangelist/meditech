# MEDITECH

> MEDITECH (Medical Information Technology, Inc.) is an electronic health record vendor serving
> community hospitals and health systems, primarily through its MEDITECH Expanse platform. Its
> API program is delivered through the Greenfield Workspace -- a registration-gated developer
> environment where approved app developers get interactive documentation and a sandbox to
> execute APIs against a real MEDITECH EHR.

MEDITECH does not publish its own llms.txt (checked greenfield.meditech.com, fhir.meditech.com,
ehr.meditech.com, www.meditech.com -- every candidate path either 404s, redirects to a
not-found page, or returns the byte-identical Angular SPA shell served for every URL on that
host). This file is generated by API Evangelist from MEDITECH's public apis.yml profile and
this repo's artifacts, not copied from a MEDITECH-published source.

## API Surfaces

- [MEDITECH Expanse FHIR API](https://ehr.meditech.com/ehr-solutions/greenfield-workspace): US Core FHIR R4, view-only patient-facing data (USCDI v1, DSTU2/R4 compatible), plus FHIR Scheduling APIs (Expanse customers only, listed "coming soon" by MEDITECH).
- [Greenfield API Explorer](https://greenfield.meditech.com/explorer/topic/welcome): interactive reference documentation and sandbox onboarding. Publicly reachable in a browser but client-rendered (Angular SPA) and robots-disallowed, so it cannot be machine-fetched.
- [Traverse Exchange](https://ehr.meditech.com/ehr-solutions/meditech-interoperability): MEDITECH's national data exchange network and TEFCA on-ramp, connecting 700+ facilities across 41 US states plus Canadian deployments.

## Authentication

SMART on FHIR OAuth 2.0, authorization_code grant with PKCE (S256). Live discovery document:
https://greenfield-prod-apis.meditech.com/.well-known/smart-configuration
client_credentials is advertised by the discovery document but was tested and confirmed NOT
enabled for the complimentary sandbox tier (HTTP 400 unauthorized_client).

## Access Model

No public pricing, no self-serve signup. Registration is a Greenfield Workspace request
reviewed by MEDITECH. See: https://ehr.meditech.com/ehr-solutions/greenfield-workspace

## Write Surface

Read-only for 31 of 33 exposed FHIR resources. Two resources accept writes: Communication
(create) and QuestionnaireResponse (create, update). No supported path exists to book/
reschedule an appointment or register a patient through Greenfield.
